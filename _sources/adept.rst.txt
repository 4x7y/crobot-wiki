Adept Cobra adapter
===================

Header: ``crobot/hardware/adept.hpp``. Class: ``crobot::hardware::Adept``.
Use ``Adept::instance()`` to access the singleton. ``initialize`` and
``calibrate`` prepare the connection/device through the expected lab server;
the server and controller-side programs are not implemented by this class.

Commands and units
------------------

``move`` requests a Cartesian move, ``move_straight`` a straight-line move, and
``move_and_wait`` the adapter's blocking move command. Coordinates are
``(x, y, z, roll)`` in meters and radians. The implementation converts them to
millimeters and degrees for transmission. ``set_speed`` sends a speed factor;
interpret it according to the configured controller/server.

``enable_alter_mode``, ``alter`` and ``disable_alter_mode`` implement incremental
path modification. The source defines a 16 ms cycle. An alter increment is a
position/orientation change per cycle, not a velocity vector without a time
conversion. ``get_position`` reads the pose;
``map_qpos2xpos`` and ``map_xpos2qpos`` convert the adapter's four-coordinate
representation.

The class defines hard/soft limits, but their presence does not establish that
every command is checked against all limits. Read the called implementation and
use the lab's current operating limits. A returned success indicates the
adapter's operation succeeded, not that an arbitrary planned motion was
collision-checked.

Read ``examples/adept_test/main.cpp`` with the current lab operator before
launching it; it is a physical-device experiment. For first-time library
onboarding use :doc:`quickstart` and :doc:`hybrid_control`.
