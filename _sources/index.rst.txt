CRobot: a lab guide
===================

CRobot is the lab's C++17 library for robot models, kinematics and dynamics,
inverse kinematics, control, MuJoCo simulation, mesh processing, grasping,
motion planning, and state estimation. Selected APIs are also available in
Python through ``pycrobot``.

Start with :doc:`setup`, then work through :doc:`quickstart`. The first exercise
runs without a robot or a display. Read :doc:`conventions` before adapting a
controller or passing state between modules.

Choose your route
-----------------

* **New lab member:** :doc:`overview` → :doc:`setup` → :doc:`quickstart` →
  :doc:`conventions` → :doc:`simulation`.
* **Robot control:** :doc:`kdl` → :doc:`ik` → :doc:`planning` → :doc:`control`
  → :doc:`hybrid_control`.
* **Object and grasp research:** :doc:`geometry` → :doc:`patch_tree` →
  :doc:`grasping`, with :doc:`optimization` for custom objectives.
* **Python analysis:** :doc:`python`; check its coverage before porting C++.
* **Library development:** :doc:`development`, :doc:`known_issues` and
  :doc:`reference`.

Each module guide identifies its CMake target, main abstractions, examples,
and implementation limits. :doc:`reference` provides a complete file catalogue
of ``crobot/``, including implementation and bundled support files. This guide
describes this checkout; older experiment names and comments can be misleading.
