Source and API reference
========================

Use the module guides for concepts and workflows; use this catalogue to locate
the exact declaration or implementation in the same checkout as the manual.
Every file under ``crobot/`` appears in one of the catalogues below. Source links
are downloadable snapshots included in the HTML build, so they also work when
the manual is shared offline.

The catalogue groups header/implementation families and shows declared-type
hints where available. It includes internal helpers, incomplete interfaces,
bundled third-party code, build files and generated-header templates. These are
labelled in the guides; listing a file does not make it a supported public API.
For extracted member signatures, build the separate Doxygen browser described
in :doc:`development`.
