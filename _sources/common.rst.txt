Common utilities
================

Link target: ``crobot``. Namespace: ``crobot::common`` for the library utilities;
logging and assertion macros are available at global scope.

Use the common layer for program infrastructure shared by examples. The
complete file list is :doc:`api/common`.

.. list-table:: Entry points
   :header-rows: 1

   * - Header
     - Purpose and usage
   * - ``logging.hpp``, ``console.hpp``
     - ``CROBOT_LOG_INFO``, warning/error logging and console output. Logging
       uses format strings with ``{}`` substitutions.
   * - ``assert.hpp``
     - Runtime checks at different severities and compile-time assertions.
       Inspect the selected macro's behavior; a log message is not an exception
       handling strategy.
   * - ``args.hpp``
     - Argument parser, help flags, typed values and parse exceptions.
       Follow ``examples/hello_world/main.cpp`` for a complete CLI.
   * - ``vector_mapper.hpp``
     - ``VectorMapper`` maps named variables between different vector layouts.
       Useful for robot-model versus device joint ordering.
   * - ``uri.hpp``, ``resource.hpp``
     - URI representation and abstract file-like resource access. ``Resource``
       requires a concrete implementation; it is not a universal model loader.
   * - ``stl_reader.hpp``
     - Bundled STL mesh reader. The higher-level mesh pipeline uses
       ``geometry::MeshIO``.
   * - ``tabulate.hpp``
     - Bundled formatted-table utility used by model and device diagnostics.

A command-line program should catch ``common::Help``, ``ParseError`` and
``ValidationError``, print the parser's usage, and return a meaningful exit
status. The parser only validates command syntax; validate model names, vector
sizes and file content in the experiment itself.

Resource paths
--------------

``crobot/config.hpp`` is generated by CMake. ``CROBOT_RESOURCE_LOCAL_PATH`` is
the configured checkout's absolute ``resources/`` path;
``CROBOT_RESOURCE_GLOBAL_PATH`` describes the install location. Moving a
checkout after configuring can leave the former stale. Other examples use
literal relative paths; check their ``main.cpp`` before launching from an IDE.
